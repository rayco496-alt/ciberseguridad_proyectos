# Proyectos de Ciberseguridad - Rayco

Este repositorio contiene scripts desarrollados durante mi formación en ciberseguridad y criptografía.

## Proyectos
*   **login_vulnerable.py**: Simulador de una vulnerabilidad de Inyección SQL (SQLi) en un sistema de login, demostrando técnicas de bypass de autenticación.
*   **gestor_db.py**: Script de gestión de base de datos usando Python y SQLite3, con inserción y consultas seguras.
